## 📌 Project Overview
This project provides a comprehensive interactive dashboard and data analytics evaluation focused on mobile game monetization, player segmentation, and in-app purchase (IAP) performance. The primary objective is to analyze player engagement metrics, spending behavior across different tiers, session lengths, and conversion funnels to help optimize in-game revenue streams and user retention strategies.

The analysis was initially processed and aggregated using **Microsoft Excel** (Data Cleaning & Preparation) and further developed into a fully interactive, dynamic visualization dashboard using **Tableau Public**.

## 💡 Key Analytical Insights
Based on the dashboard analysis, several critical findings regarding player behavior and monetization were identified:

1. **Monetization Tiers (Whales vs. Minnows):**  
   Analyzed revenue contribution across distinct player spending segments (*Whale*, *Dolphin*, *Minnow*), highlighting how high-value segments drive the bulk of total game revenue while lower tiers represent volume.
2. **Device & Session Optimization:**  
   Explored average session lengths and performance metrics across platforms (iOS, Android, Unknown) to understand user engagement patterns and platform-specific retention triggers.
3. **Conversion Funnel & Timing Analysis:**  
   Tracked payer conversion rates and purchase timing (measured in days after install) to pinpoint peak monetization windows during the player lifecycle.
4. **Genre & Revenue Correlation:**  
   Evaluated revenue distribution across various game genres to identify top-performing categories that yield the highest in-app purchase returns.
